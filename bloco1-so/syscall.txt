# PARTE B — Programa C com write() direto

# Cole aqui o código de syscall_direto.c que você escreveu:

#include <unistd.h>
#include <string.h>

int main() {
    const char *mensagem = "ola\n";
    write(1, mensagem, strlen(mensagem));
    return 0;
}

# PARTE C — Questões de síntese

# 1. A apresentação mostrou que "instruções de I/O são privilegiadas". 
#    Com base no que o strace revelou, explique com suas palavras como um programa
#    de usuário consegue fazer I/O sem executar instruções privilegiadas diretamente.

Resposta 1:
O programa chama o kernel usando syscalls. O kernel, que é privilegiado, executa o I/O e volta o resultado para o programa.

#    dispositivos, sem intervenção direta da CPU principal. Qual elemento do sistema 
#    operacional moderno herda esse papel? 

Resposta 2:
O kernel e os drivers intervêm na memória e nos dispositivos de I/O.
